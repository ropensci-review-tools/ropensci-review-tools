# Print goodpractice results

## Description

Print goodpractice results

## Usage

```r
# S3 method for goodPractice
print(x, groups = NULL, positions_limit = 5, ...)
```

## Arguments

* `x`: Object of class `goodPractice`, as returned by `[gp()](gp)`.
* `groups`: Name of check groups for which to print results, as vector of
one or more of `[all_check_groups()](all_check_groups)`.
* `positions_limit`: How many positions to print at most.
* `...`: Unused, for compatibility with `[base::print()](https://rdrr.io/r/base/print.html)` generic method.
